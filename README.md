# MetaPerson - Unity MetaQuest Lipsync 
This project shows my Final Degree Thesis, a virtual assistant for the University of Cádiz.

## Requirements

- Unity 2021.3.19f1 or newer

## Getting Started

1. Install Unity 2021.3.19f1 or newer.
2. Clone this repository to your computer.
3. Open the project in Unity.
4. Open the `\Assets\Scenes\MainScene` scene.
5. Run the project and see how the MetaPerson avatar on the scene is animated with the Oculus Lipsync.

## Languages used
1. C#
2. Python
3. JavaScript
